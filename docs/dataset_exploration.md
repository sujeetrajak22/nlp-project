# Dataset Exploration Documentation

## AG News Dataset

### Overview
The AG News dataset is a collection of news articles gathered from more than 2,000 news sources by the Academic Torrents ComeToMyHead platform. It was introduced by Xiang Zhang et al. in 2015 for benchmarking text classification models.

**Citation:**
> Zhang, X., Zhao, J., & LeCun, Y. (2015). Character-level Convolutional Networks for Text Classification. NeurIPS 2015.

---

## Dataset Details

| Property | Value |
|----------|-------|
| Dataset Name | AG News |
| Source | HuggingFace: `datasets.load_dataset("ag_news")` |
| License | Academic/Research use |
| Classes | 4 |
| Train samples | 120,000 |
| Test samples | 7,600 |
| Total samples | 127,600 |

### Categories

| Label ID | Category | Description |
|----------|----------|-------------|
| 0 | World | International news, politics, conflicts |
| 1 | Sports | All sports news, matches, athletes |
| 2 | Business | Finance, economics, companies, markets |
| 3 | Sci/Tech | Science, technology, computers, research |

### Class Distribution (AG News is balanced)
- World: 30,000 train / 1,900 test
- Sports: 30,000 train / 1,900 test
- Business: 30,000 train / 1,900 test
- Sci/Tech: 30,000 train / 1,900 test

*(Note: Exact statistics generated by running `scripts/download_dataset.py`)*

---

## Data Format

Each sample contains:
- `text`: The article title and description concatenated
- `label`: Integer class label (0–3)

---

## Why AG News?

1. **Well-established benchmark:** Used in dozens of NLP papers, easy to compare results
2. **4 clear categories:** Sufficient variety without being too complex
3. **Balanced classes:** No class imbalance problem to manage
4. **Medium size:** 120K samples — large enough to train meaningful models, small enough to process locally
5. **Easy access:** Available via HuggingFace datasets, no scraping required
6. **Clean text:** Pre-cleaned, no HTML artifacts in main text
7. **Strong baselines exist:** Literature results available for comparison

## Exploration Results

*(Generated after running `scripts/download_dataset.py` and `notebooks/01_dataset_exploration.ipynb`)*

Actual statistics will appear here after execution. The following fields are computed and saved to `data/processed/stats.json`:

- `total_documents`: Total number of articles
- `num_categories`: 4
- `avg_text_length`: Average character length
- `min_text_length`: Minimum character length
- `max_text_length`: Maximum character length
- `avg_words`: Average word count per article
- `vocabulary_size`: Number of unique tokens
- `missing_values`: Count of null entries
- `duplicate_count`: Count of duplicate articles
- `top_words`: 20 most frequent words overall
- `top_words_per_category`: 10 most frequent per category
- `label_distribution`: Count per category
- `text_length_distribution`: Histogram bins
